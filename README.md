## About Davis Student Resource Compass

Davis Student Resource Compass is built to help UC Davis students discover useful campus resources in a faster, more structured way. Instead of relying on scattered directories or manual searching, the platform brings resource discovery into one responsive web interface that can guide students toward relevant support based on context and availability.

The project combines an interactive campus map with semantic resource matching and predictive suggestions, making it easier to explore nearby options and compare what is currently available. Its community-driven submission flow also helps keep listings adaptable over time, while multilingual and accessibility support broadens the range of students who can use the platform comfortably.

- Semantic resource matching for more relevant discovery results

Open the site and use the campus map to explore resource locations around UC Davis. Search by need, browse suggested entries, and review availability details when they are shown.
